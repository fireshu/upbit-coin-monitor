⚙️ API 서버 연결 설정

로컬 백엔드 서버(server.py) 또는 외부 프록시 서버의 도메인/IP 주소를 설정합니다. 기본 포트는 5000번입니다.

⚠️ HTTPS 보안 연결 필수 안내

현재 깃허브 배포 페이지(HTTPS)로 접속하신 경우, 보안 정책(Mixed Content)으로 인해 비보안 로컬 API(http://localhost:5000 등) 연결이 브라우저에서 자동 차단됩니다.
모바일 연동 등 외부 연결을 원하시면, PC 터미널에서 ngrok http 5000을 구동하여 발급된 HTTPS 보안 주소(예: https://xxxx.ngrok-free.app)를 복사해서 이곳에 입력하고 저장해 주셔야 정상 작동합니다.

본 사이트는 공개 API의 측정 데이터를 표시할 뿐이며 투자 권유가 아닙니다.
